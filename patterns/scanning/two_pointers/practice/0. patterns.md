# Two Pointers Patterns Cheat Sheet

## Pattern: Opposite-End Two Pointers

**Use when:** A pair or boundary decision can be improved by discarding one side at a time.

**Pattern:** Start at both ends and move the pointer whose current value cannot participate in a better answer.

**Key insight:** Sorted order or a geometric bound makes one pointer movement safe.

### Key skills

- Prove which side can be discarded
- Skip duplicates after recording a result
- Preserve the required output indices when sorting
