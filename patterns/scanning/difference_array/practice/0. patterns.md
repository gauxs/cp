# Difference Array Patterns Cheat Sheet

## Pattern: Offline Range Updates

**Use when:** Many inclusive range additions must be applied before the final values are read.

**Pattern:** Record each update as boundary events, then prefix-sum the differences.

**Key insight:** Values inside a range do not change relative to each other; only the boundaries change.

### Key skills

- Convert inclusive endpoints correctly
- Add a sentinel position for `right + 1`
- Compress coordinates when the domain is sparse
