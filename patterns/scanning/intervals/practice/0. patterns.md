# Intervals Patterns Cheat Sheet

## Pattern: Sort Then Scan Intervals

**Use when:** Intervals need merging, conflict checks, or greedy placement after ordering.

**Pattern:** Sort by start (or end), then one pass: merge overlaps, detect conflicts, or greedily pick / skip.

**Key insight:** Sorting turns timeline decisions into a linear scan.

### Key skills

- comparator on start vs end
- overlap / conflict check against last end
- greedy “earliest finishing” selection

## Pattern: Sweep Line / Concurrent Intervals

**Use when:** Need how many intervals are active at once (rooms, resources).

**Pattern:** Min-heap of end times while scanning by start, or sweep line of start/end events.

**Key insight:** Active count is the size of the heap (or running sum on the sweep).

### Key skills

- min-heap of end times
- event sweep ($+1$ start, $-1$ end)

1. [Meeting Rooms II](https://leetcode.com/problems/meeting-rooms-ii/)
