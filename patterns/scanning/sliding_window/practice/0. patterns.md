# Sliding Window Patterns Cheat Sheet

## Pattern: Fixed Size Window

**Use when:** Window length is fixed; slide across the array or string.

**Pattern:** Maintain state for exactly $k$ elements; advance both ends together.

**Key insight:** Only position changes - no expand/shrink logic.

### Key skills

- running sum / frequency for window size $k$
- anagram / permutation matching with frequency maps

### Problems

1. [Maximum Average Subarray I](https://leetcode.com/problems/maximum-average-subarray-i/)
2. [Find All Anagrams in a String](https://leetcode.com/problems/find-all-anagrams-in-a-string/)
3. [Permutation in String](https://leetcode.com/problems/permutation-in-string/)

## Pattern: Variable Size Window

**Use when:** Find longest or shortest contiguous segment satisfying a constraint.

**Pattern:** Expand with `right`; while invalid, shrink with `left`; record best at each valid step.

**Key insight:** Two pointers track window boundaries; condition function drives shrink.

### Key skills

- frequency map maintenance
- longest vs shortest recording logic

### Problems

1. [Longest Substring Without Repeating Characters](https://leetcode.com/problems/longest-substring-without-repeating-characters/)
2. [Minimum Window Substring](https://leetcode.com/problems/minimum-window-substring/)
3. [Longest Repeating Character Replacement](https://leetcode.com/problems/longest-repeating-character-replacement/)
4. [Max Consecutive Ones III](https://leetcode.com/problems/max-consecutive-ones-iii/)
5. [Fruit Into Baskets](https://leetcode.com/problems/fruit-into-baskets/)

## Pattern: At Most / Exactly K Distinct

**Use when:** Count or optimize subarrays with a bound on distinct elements or similar frequency constraints.

**Pattern:** Track counts in window; for exactly $K$, use `atMost(K) - atMost(K-1)`.

**Key insight:** “Exactly K” reduces to two “at most” counts.

### Key skills

- frequency counting in window
- inclusion-exclusion for exact K

### Problems

1. [Longest Substring with At Most K Distinct Characters](https://leetcode.com/problems/longest-substring-with-at-most-k-distinct-characters/)
2. [Subarrays with K Different Integers](https://leetcode.com/problems/subarrays-with-k-different-integers/)
3. [Number of Substrings Containing All Three Characters](https://leetcode.com/problems/number-of-substrings-containing-all-three-characters/)

## Pattern: Sum or Product Constraint

**Use when:** Window sum or product must meet a threshold (often with nonnegative values).

**Pattern:** Expand while under target; shrink when constraint violated; count or minimize length.

**Key insight:** Monotonic sum/product enables greedy shrink for nonnegative arrays.

### Key skills

- running sum / product
- recognize that negative numbers break monotonic window movement

### Problems

1. [Minimum Size Subarray Sum](https://leetcode.com/problems/minimum-size-subarray-sum/)
2. [Subarray Product Less Than K](https://leetcode.com/problems/subarray-product-less-than-k/)
