# Prefix Sum Patterns Cheat Sheet

## Pattern: Prefix Sum Range Query

**Use when:** Many immutable range sums or a left/right aggregate must be answered.

**Pattern:** Build cumulative sums and subtract two prefix boundaries.

**Key insight:** Every contiguous range is the difference of two prefixes.

### Key skills

- Use an initial zero prefix
- Keep prefix and array indices distinct

### Problems

1. [Range Sum Query - Immutable](https://leetcode.com/problems/range-sum-query-immutable/)
2. [Find Pivot Index](https://leetcode.com/problems/find-pivot-index/)

## Pattern: Prefix Sum with Frequency Map

**Use when:** Count subarrays with a target sum, binary goal, or divisible sum.

**Pattern:** For each current prefix, count compatible earlier prefixes before recording it.

**Key insight:** The desired subarray condition can be rewritten as a relation between two prefix values.

### Key skills

- Seed frequency zero with one occurrence
- Normalize negative remainders
- Use a wide integer type for cumulative sums

### Problems

1. [Subarray Sum Equals K](https://leetcode.com/problems/subarray-sum-equals-k/)
2. [Binary Subarrays With Sum](https://leetcode.com/problems/binary-subarrays-with-sum/)
3. [Subarray Sums Divisible by K](https://leetcode.com/problems/subarray-sums-divisible-by-k/)
