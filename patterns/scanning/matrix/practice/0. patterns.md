# Matrix Scanning Patterns Cheat Sheet

## Pattern: Layer and Boundary Traversal

**Use when:** A matrix must be visited in spiral, diagonal, ring, or other coordinate-defined order.

**Pattern:** Maintain explicit boundaries or a direction state and shrink or turn after completing a side.

**Key insight:** Traversal order is determined by a small boundary invariant rather than graph reachability.

### Key skills

- Guard against revisiting the final row or column
- Encode directions as row/column deltas
- Separate traversal state from output

### Problems

1. [Spiral Matrix](https://leetcode.com/problems/spiral-matrix/)
2. [Spiral Matrix II](https://leetcode.com/problems/spiral-matrix-ii/)
3. [Diagonal Traverse](https://leetcode.com/problems/diagonal-traverse/)

## Pattern: In-Place Matrix Transformation

**Use when:** Cells must be rotated, marked, or updated while using constant auxiliary space.

**Pattern:** Decompose the transformation into reversible geometric operations or encode deferred state in existing cells.

**Key insight:** Transpose plus reflection performs rotation; reserved markers separate old state from new state.

### Key skills

- Transpose only one triangular half
- Choose the correct reflection direction
- Use first-row/first-column markers safely

### Problems

1. [Rotate Image](https://leetcode.com/problems/rotate-image/)
2. [Set Matrix Zeroes](https://leetcode.com/problems/set-matrix-zeroes/)
3. [Game of Life](https://leetcode.com/problems/game-of-life/)
