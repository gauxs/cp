# Greedy Patterns Cheat Sheet

## Pattern: Greedy with Sorting

**Use when:** Local optimal choice becomes obvious after sorting by a key.

**Pattern:** Sort, then one pass making greedy picks.

**Key insight:** Proof usually shows no benefit from deviating from sorted greedy choice.

### Key skills

- choosing sort key (start vs end)
- exchange argument intuition

### Problems

1. [Increasing Triplet Subsequence](https://leetcode.com/problems/increasing-triplet-subsequence/)
2. [Queue Reconstruction by Height](https://leetcode.com/problems/queue-reconstruction-by-height/)

---

## Pattern: Greedy Reachability

**Use when:** Each position provides reach, fuel, or progress and the task asks whether or how few steps can finish.

**Pattern:** Track the farthest reachable boundary or the cumulative surplus while scanning.

**Key insight:** Only the best frontier or the last impossible prefix matters; individual paths need not be explored.

### Key skills

- Separate current-layer reach from next-layer reach
- Reset a candidate start after a negative prefix

### Problems

1. [Jump Game](https://leetcode.com/problems/jump-game/)
2. [Jump Game II](https://leetcode.com/problems/jump-game-ii/)
3. [Gas Station](https://leetcode.com/problems/gas-station/)

---

## Pattern: Greedy Scheduling and Partitioning

**Use when:** Tasks or symbols impose global spacing or last-occurrence constraints.

**Pattern:** Commit a boundary only when every item seen so far can safely finish there.

**Key insight:** A compact summary of future obligations determines the earliest valid decision.

### Key skills

- Track last occurrence
- Derive idle slots from the most frequent task

### Problems

1. [Task Scheduler](https://leetcode.com/problems/task-scheduler/)
2. [Partition Labels](https://leetcode.com/problems/partition-labels/)
