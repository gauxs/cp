# Greedy Patterns Cheat Sheet

## Pattern: Greedy with Sorting

**Use when:** Local optimal choice becomes obvious after sorting by a key.

**Pattern:** Sort, then one pass making greedy picks.

**Key insight:** Proof usually shows no benefit from deviating from sorted greedy choice.

### Key skills

- choosing sort key (start vs end)
- exchange argument intuition
