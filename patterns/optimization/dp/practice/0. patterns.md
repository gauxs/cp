# Dynamic Programming Patterns Cheat Sheet

Inspired by [Dynamic Programming Summary](https://leetcode.com/discuss/general-discussion/592146/dynamic-programming-summary) by [@richenyunqi](https://leetcode.com/richenyunqi).

## Pattern: 1D Linear DP

**Use when:** State is one index; transition uses a few previous indices.

**Pattern:** `dp[i]` from `dp[i-1]`, `dp[i-2]`, etc.

**Key insight:** Fibonacci-style recurrence on a line.

### Key skills

- rolling two variables instead of full array
- circular arrays (mod index)

### Problems

1. [Fibonacci Number](https://leetcode.com/problems/fibonacci-number/)
2. [Climbing Stairs](https://leetcode.com/problems/climbing-stairs/)
3. [Min Cost Climbing Stairs](https://leetcode.com/problems/min-cost-climbing-stairs/)
4. [House Robber](https://leetcode.com/problems/house-robber/)
5. [House Robber II](https://leetcode.com/problems/house-robber-ii/)
6. [Delete and Earn](https://leetcode.com/problems/delete-and-earn/)
7. [Arithmetic Slices](https://leetcode.com/problems/arithmetic-slices/)

## Pattern: 0/1 Knapsack and Subset Sum

**Use when:** Each item used at most once; target sum / capacity / difference.

**Pattern:** `dp[i][w]` or boolean reachability over index and weight.

**Key insight:** Subset-sum structure with inclusion / exclusion at each index.

### Key skills

- target sum from subset sum transform
- bitset optimization

### Problems

1. [Partition Equal Subset Sum](https://leetcode.com/problems/partition-equal-subset-sum/)
2. [Target Sum](https://leetcode.com/problems/target-sum/)
3. [Last Stone Weight II](https://leetcode.com/problems/last-stone-weight-ii/)
4. [Ones and Zeroes](https://leetcode.com/problems/ones-and-zeroes/)

## Pattern: Unbounded Knapsack / Coin Change

**Use when:** Items or coins reusable; count ways or min coins.

**Pattern:** `dp[amount]` updated from all coin sizes; order may matter for counting.

**Key insight:** Inner loop order distinguishes permutations vs combinations.

### Key skills

- min vs count recurrences
- combination-sum loop order

### Problems

1. [Coin Change](https://leetcode.com/problems/coin-change/)
2. [Coin Change 2](https://leetcode.com/problems/coin-change-2/)
3. [Combination Sum IV](https://leetcode.com/problems/combination-sum-iv/)

## Pattern: Sequence DP (LIS Style)

**Use when:** `dp[i]` depends on all `j < i` satisfying a predicate.

**Pattern:** Nested loops or patience sorting + binary search for LIS.

**Key insight:** Often $O(N^2)$ DP; LIS has $O(N \log N)$ greedy+BS variant.

### Key skills

- patience sorting for LIS
- envelope nesting (sort + LIS on second dimension)

### Problems

1. [Longest Increasing Subsequence](https://leetcode.com/problems/longest-increasing-subsequence/)
2. [Russian Doll Envelopes](https://leetcode.com/problems/russian-doll-envelopes/)
3. [Maximum Product Subarray](https://leetcode.com/problems/maximum-product-subarray/)

## Pattern: String Alignment DP

**Use when:** Two strings; edit / match / decode on prefixes.

**Pattern:** 2D `dp[i][j]` on prefix lengths with insert/delete/replace/match.

**Key insight:** Grid DP on `(i, j)` string prefixes.

### Key skills

- tight base cases on empty prefix
- rolling row for space

### Problems

1. [Edit Distance](https://leetcode.com/problems/edit-distance/)
2. [Decode Ways](https://leetcode.com/problems/decode-ways/)
3. [Distinct Subsequences](https://leetcode.com/problems/distinct-subsequences/)
4. [Longest Common Subsequence](https://leetcode.com/problems/longest-common-subsequence/)
5. [Delete Operation for Two Strings](https://leetcode.com/problems/delete-operation-for-two-strings/)

## Pattern: Interval DP

**Use when:** Optimal answer on interval `[l, r]` with split point `k`.

**Pattern:** `dp[l][r]` from `dp[l][k]` and `dp[k+1][r]` or burst-last-balloon style.

**Key insight:** Primary home for interval **DP** — not Scanning → Intervals.

### Key skills

- choosing split / last operation index
- padding boundaries (virtual elements)

### Problems

1. [Burst Balloons](https://leetcode.com/problems/burst-balloons/)
2. [Minimum Score Triangulation of Polygon](https://leetcode.com/problems/minimum-score-triangulation-of-polygon/)
3. [Strange Printer](https://leetcode.com/problems/strange-printer/)

---

## Pattern: Line DP with Per-Position Choices

**Use when:** Each position picks among a small fixed set (colors, actions).

**Pattern:** `dp[i][choice]` along a line with local cost constraints.

**Key insight:** State is index + last choice / min cost so far.

### Problems

1. [Paint House](https://leetcode.com/problems/paint-house/)

---

## Pattern: Scheduling DP

**Use when:** Jobs with start/end/profit; pick non-overlapping subset for max profit.

**Pattern:** Sort by end; `dp[i]` = best using jobs up to $i$ with binary search on last compatible job.

**Key insight:** Sort + next compatible index lookup.

### Problems

1. [Maximum Profit in Job Scheduling](https://leetcode.com/problems/maximum-profit-in-job-scheduling/)

---

## Pattern: Grid Path DP

**Use when:** Move on grid with limited directions; min/max path cost or count paths.

**Pattern:** `dp[row][col]` from top/left neighbors.

**Key insight:** Often $O(rows \times cols)$ with obstacle handling.

### Problems

1. [Unique Paths](https://leetcode.com/problems/unique-paths/)
2. [Unique Paths II](https://leetcode.com/problems/unique-paths-ii/)
3. [Minimum Path Sum](https://leetcode.com/problems/minimum-path-sum/)
4. [Dungeon Game](https://leetcode.com/problems/dungeon-game/)

---

## Pattern: Tree DP

**Use when:** Answer aggregates over subtrees with per-node decisions.

**Pattern:** Post-order DFS; combine child DP at each node.

**Key insight:** Return pairs (e.g. with/without robbing node) from subtrees.

### Problems

1. [House Robber III](https://leetcode.com/problems/house-robber-iii/)
2. [Binary Tree Maximum Path Sum](https://leetcode.com/problems/binary-tree-maximum-path-sum/)

---

## Pattern: Digit DP

**Use when:** Count numbers in range with digit constraints.

**Pattern:** DP on position + tight bound + leading zeros.

**Key insight:** State tracks index and whether still matching upper bound.

### Problems

1. [Numbers With Repeated Digits](https://leetcode.com/problems/numbers-with-repeated-digits/)
2. [Non-negative Integers without Consecutive Ones](https://leetcode.com/problems/non-negative-integers-without-consecutive-ones/)

---

## Pattern: Bitmask / Subset DP

**Use when:** Choose subset of items with assignment or partition constraints.

**Pattern:** `dp[mask]` over subsets; often exponential in $n$.

**Key insight:** Bitmask encodes which elements are already used.

### Problems

1. [Maximum Students Taking Exam](https://leetcode.com/problems/maximum-students-taking-exam/)
2. [Partition to K Equal Sum Subsets](https://leetcode.com/problems/partition-to-k-equal-sum-subsets/)

---

## Pattern: Memory-Optimized DP

**Use when:** Full table is clear but only recent rows/columns matter.

**Pattern:** Rolling array, compressed dimensions, or bitset.

**Key insight:** Same recurrence, smaller footprint.

### Problems

1. [Maximum Score from Performing Multiplication Operations](https://leetcode.com/problems/maximum-score-from-performing-multiplication-operations/)
