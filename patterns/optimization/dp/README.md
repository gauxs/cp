# Dynamic Programming

## Overview

Solve overlapping subproblems with optimal substructure by defining a state and transitions. Practice content will migrate from `paradigms/dp/`.

## Key Observations

1. Identify what a state represents and what answers it needs.
2. Prefer the smallest state that still decides the answer.
3. Interval DP belongs here when the hard part is `dp[l][r]` transitions — not under Intervals.
