# Patterns

Interview recognition families. Every problem has **one primary home** - either under Patterns or under Algorithms / Data Structures.

## Groups

| Group | Topics |
| --- | --- |
| [Optimization](optimization/README.md) | Dynamic Programming, Greedy |
| [Scanning](scanning/README.md) | Sliding Window, Two Pointers, Prefix Sum, Difference Array, Intervals |
| [Divide and Conquer](divide_and_conquer/README.md) | Split + combine |

## Placement (first match wins)

1. Named algorithm is the lesson → `algorithms/…`
2. Data structure is the lesson → `data_structures/…`
3. DP state / transitions are the hard part → `patterns/optimization/dp`
4. Greedy choice is the hard part → `patterns/optimization/greedy`
5. Contiguous subarray / substring window → `patterns/scanning/sliding_window`
6. Coordinated pointer movement is the hard part → `patterns/scanning/two_pointers`
7. Range aggregate or relation between prefixes → `patterns/scanning/prefix_sum`
8. Offline range updates via boundary events → `patterns/scanning/difference_array`
9. Intervals / scheduling on `[start, end]` → `patterns/scanning/intervals`
10. Split + combine divide and conquer → `patterns/divide_and_conquer`
