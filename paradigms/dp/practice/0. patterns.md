# Dynamic Programming Patterns

This file organizes dynamic programming problems **pattern-wise**, heavily inspired by  
[Dynamic Programming Summary](https://leetcode.com/discuss/general-discussion/592146/dynamic-programming-summary) by [@richenyunqi](https://leetcode.com/richenyunqi) and the notes in `paradigms/dp/README.md`.

The goal is to quickly map a problem to a **pattern**, then recall the right state definition and transitions.

---

## 1. 1D DP on Linear State (Fibonacci / Climbing Stairs / House Robber)

**Idea:** State is a single index or step, and transitions depend on a few previous indices (`dp[i-1]`, `dp[i-2]`, etc.).

**Problems:**

1. [Fibonacci Number](https://leetcode.com/problems/fibonacci-number/)
2. [Climbing Stairs](https://leetcode.com/problems/climbing-stairs/)
3. [Min Cost Climbing Stairs](https://leetcode.com/problems/min-cost-climbing-stairs/)
4. [House Robber](https://leetcode.com/problems/house-robber/)
5. [House Robber II](https://leetcode.com/problems/house-robber-ii/)
6. [Delete and Earn](https://leetcode.com/problems/delete-and-earn/)
7. [Arithmetic Slices](https://leetcode.com/problems/arithmetic-slices/)

---

## 2. 0/1 Knapsack and Subset-Sum DP

**Idea:** Each item/number can be taken at most once; state usually tracks index + capacity/target/difference.

**Problems:**

1. [Partition Equal Subset Sum](https://leetcode.com/problems/partition-equal-subset-sum/)
2. [Target Sum](https://leetcode.com/problems/target-sum/)
3. [Last Stone Weight II](https://leetcode.com/problems/last-stone-weight-ii/)  ← from original “good questions”
4. [Ones and Zeroes](https://leetcode.com/problems/ones-and-zeroes/)  ← also appears under memory-optimized DP

---

## 3. Unbounded Knapsack / Coin Change

**Idea:** Each item/value can be used unlimited times; order may or may not matter.

**Problems:**

1. [Coin Change](https://leetcode.com/problems/coin-change/)
2. [Coin Change 2](https://leetcode.com/problems/coin-change-2/)
3. [Combination Sum IV](https://leetcode.com/problems/combination-sum-iv/)

---

## 4. Sequence DP (LIS / Envelopes / Subsequence Style)

**Idea:** 1D sequence where `dp[i]` depends on previous positions `j < i` (often nested loops, `O(n²)`).

**Problems:**

1. [Longest Increasing Subsequence](https://leetcode.com/problems/longest-increasing-subsequence/)
2. [Russian Doll Envelopes](https://leetcode.com/problems/russian-doll-envelopes/)  ← from original “good questions”
3. [Maximum Subarray](https://leetcode.com/problems/maximum-subarray/) (Kadane, can be seen as DP)
4. [Maximum Product Subarray](https://leetcode.com/problems/maximum-product-subarray/)

---

## 5. String Edit / Alignment DP (2D on Two Strings)

**Idea:** 2D DP on prefixes of two strings; operations like insert/delete/replace/match/mismatch.

**Problems:**

1. [Edit Distance](https://leetcode.com/problems/edit-distance/)
2. [Decode Ways](https://leetcode.com/problems/decode-ways/)
3. [Distinct Subsequences](https://leetcode.com/problems/distinct-subsequences/)
4. [Longest Common Subsequence](https://leetcode.com/problems/longest-common-subsequence/)
5. [Delete Operation for Two Strings](https://leetcode.com/problems/delete-operation-for-two-strings/)

---

## 6. Interval / Range DP (Merge-Intervals Style)

**Idea:** State is an interval `[l, r]`. We try all split points `k` between `l` and `r` and combine `dp[l][k]` and `dp[k+1][r]`.

**Problems:**

1. [Burst Balloons](https://leetcode.com/problems/burst-balloons/)  ← from original “good questions”
2. [Minimum Score Triangulation of Polygon](https://leetcode.com/problems/minimum-score-triangulation-of-polygon/)
3. [Strange Printer](https://leetcode.com/problems/strange-printer/)

---

## 7. Paint House / Line DP with Choices Per Position

**Idea:** DP along a line of positions (houses, days, etc.) with a small fixed set of choices per position (colors, actions).

**Problems:**

1. [Paint House II](https://www.lintcode.com/problem/516)  ← from original “good questions”
2. [Paint House](https://leetcode.com/problems/paint-house/) (similar idea; different source)

---

## 8. DP on Sorted Intervals / Scheduling

**Idea:** Sort intervals/jobs by start/end time, then DP to choose or skip each job with binary search or next-index lookup.

**Problems:**

1. [Maximum Profit in Job Scheduling](https://leetcode.com/problems/maximum-profit-in-job-scheduling/)  ← from original “good questions”

---

## 9. DP on Grids (2D Path DP)

**Idea:** Grid-based DP, often moving only right/down or in limited directions.

**Problems:**

1. [Unique Paths](https://leetcode.com/problems/unique-paths/)
2. [Unique Paths II](https://leetcode.com/problems/unique-paths-ii/)
3. [Minimum Path Sum](https://leetcode.com/problems/minimum-path-sum/)
4. [Dungeon Game](https://leetcode.com/problems/dungeon-game/)

---

## 10. Tree DP

**Idea:** DFS on trees where each node’s DP depends on its children’s DP values.

**Problems:**

1. [House Robber III](https://leetcode.com/problems/house-robber-iii/)
2. [Binary Tree Maximum Path Sum](https://leetcode.com/problems/binary-tree-maximum-path-sum/)

---

## 11. Digit DP

**Idea:** Count numbers with certain properties using DP over digits + tight/leading-zero flags.

**Problems:**

1. [Numbers With Repeated Digits](https://leetcode.com/problems/numbers-with-repeated-digits/)
2. [Non-negative Integers without Consecutive Ones](https://leetcode.com/problems/non-negative-integers-without-consecutive-ones/)

---

## 12. Bitmask DP / Subset DP

**Idea:** State is a bitmask representing a chosen subset; often used for TSP-style or assignment problems.

**Problems:**

1. [Maximum Students Taking Exam](https://leetcode.com/problems/maximum-students-taking-exam/)
2. [Partition to K Equal Sum Subsets](https://leetcode.com/problems/partition-to-k-equal-sum-subsets/)

---

## 13. Memory-Optimized DP

**Idea:** Same recurrence as a “full” DP but we compress rows/columns or only keep what’s needed.

**Problems:**

1. [Maximum Score from Performing Multiplication Operations](https://leetcode.com/problems/maximum-score-from-performing-multiplication-operations/)  ← from original “good questions”
2. [Ones and Zeroes](https://leetcode.com/problems/ones-and-zeroes/)  (compress dimensions)
3. [InterviewBit - Potions](https://www.interviewbit.com/problems/potions/)  ← from original “good questions”
