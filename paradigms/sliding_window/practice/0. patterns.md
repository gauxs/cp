# Sliding Window Patterns Cheat Sheet

## 1. Fixed Size Window
**Window size is constant.**  
**Pattern:** Maintain window of fixed size, slide it across the array  
**Key Insight:** Window size never changes, only position shifts

**Problems:**  
1. [Maximum Average Subarray I](https://leetcode.com/problems/maximum-average-subarray-i/)  
2. [Find All Anagrams in a String](https://leetcode.com/problems/find-all-anagrams-in-a-string/)  
3. [Permutation in String](https://leetcode.com/problems/permutation-in-string/)  

**Key Skills:** fixed window maintenance, sliding without resizing  

---

## 2. Variable Size Window (Expand/Shrink)
**Window size changes based on condition.**  
**Pattern:** Expand window (move right), shrink when condition violated (move left)  
**Key Insight:** Find longest/shortest subarray satisfying condition

**Problems:**  
1. [Longest Substring Without Repeating Characters](https://leetcode.com/problems/longest-substring-without-repeating-characters/)  
2. [Minimum Window Substring](https://leetcode.com/problems/minimum-window-substring/)  
3. [Longest Repeating Character Replacement](https://leetcode.com/problems/longest-repeating-character-replacement/)  
4. [Max Consecutive Ones III](https://leetcode.com/problems/max-consecutive-ones-iii/)  

**Key Skills:** two pointers, condition validation, window expansion/shrinking  

---

## 3. At Most / At Least K Pattern
**Window contains at most/at least K elements satisfying condition.**  
**Pattern:** Count elements in window, adjust based on constraint  
**Key Insight:** Track count of relevant elements, maintain constraint

**Problems:**  
1. [Longest Substring with At Most K Distinct Characters](https://leetcode.com/problems/longest-substring-with-at-most-k-distinct-characters/)  
2. [Subarrays with K Different Integers](https://leetcode.com/problems/subarrays-with-k-different-integers/)  
3. [Number of Substrings Containing All Three Characters](https://leetcode.com/problems/number-of-substrings-containing-all-three-characters/)  

**Key Skills:** frequency counting, constraint tracking, exact vs at-most conversion  

---

## 4. Sum / Product Constraint Window
**Window sum/product satisfies condition (>=, <=, == target).**  
**Pattern:** Track running sum/product, adjust window based on constraint  
**Key Insight:** Monotonicity in sum allows efficient window adjustment

**Problems:**  
1. [Minimum Size Subarray Sum](https://leetcode.com/problems/minimum-size-subarray-sum/)  
2. [Subarray Product Less Than K](https://leetcode.com/problems/subarray-product-less-than-k/)  
3. [Shortest Subarray with Sum at Least K](https://leetcode.com/problems/shortest-subarray-with-sum-at-least-k/)  

**Key Skills:** prefix sum, product tracking, negative number handling  

---

## 5. Monotonic Queue / Deque Window
**Window requires maintaining min/max efficiently.**  
**Pattern:** Use deque to maintain monotonic sequence  
**Key Insight:** Deque stores indices in sorted order, enables O(1) min/max access

**Problems:**  
1. [Sliding Window Maximum](https://leetcode.com/problems/sliding-window-maximum/)  
2. [Longest Continuous Subarray With Absolute Diff Less Than or Equal to Limit](https://leetcode.com/problems/longest-continuous-subarray-with-absolute-diff-less-than-or-equal-to-limit/)  

**Key Skills:** monotonic deque, index management, min/max tracking  

---

## 6. Hybrid / Advanced Sliding Window
**Combines multiple patterns - favorite for deep interviews**

**Examples:**  
1. [Longest Repeating Character Replacement](https://leetcode.com/problems/longest-repeating-character-replacement/) - Variable Window + Frequency Tracking + Character Replacement  
2. [Minimum Window Substring](https://leetcode.com/problems/minimum-window-substring/) - Variable Window + Frequency Map + Constraint Satisfaction  
3. [Shortest Subarray with Sum at Least K](https://leetcode.com/problems/shortest-subarray-with-sum-at-least-k/) - Monotonic Deque + Prefix Sum + Negative Numbers
