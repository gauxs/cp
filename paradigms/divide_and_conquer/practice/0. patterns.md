# Divide & Conquer Patterns

# 1. Split-on-Property (Semantic Divide & Conquer)

**Idea:** Certain elements make a substring/subarray invalid. Split around them and recurse.

**Why it shows up:** Great for substring problems where a condition must hold everywhere.

**Problems:**

* [Longest Nice Substring](https://leetcode.com/problems/longest-nice-substring/)
* Balanced substring variants (non-LeetCode-specific)

**Skills:** spotting “bad elements,” segment recursion, combining best segment.

---

# 2. Mid-Split + Combine (Classic D&C)

**Idea:** Split array at mid, solve left/right, handle cross-mid cases.

**Why it shows up:** This is the true foundation of D&C.

**Problems:**

* [Maximum Subarray](https://leetcode.com/problems/maximum-subarray/) (D&C version)
* [Reverse Pairs](https://leetcode.com/problems/reverse-pairs/)
* [Count of Range Sum](https://leetcode.com/problems/count-of-range-sum/)
* Merge Sort (conceptual foundation)

**Skills:** merge logic, prefix/suffix combination, cross-mid counting.

---

# 3. Quickselect / Pivot-Based D&C

**Idea:** Partition around a pivot, recurse only on the side containing the answer.

**Why it shows up:** Very common in interviews.

**Problems:**

* [Kth Largest Element in an Array](https://leetcode.com/problems/kth-largest-element-in-an-array/)
* [Median of Two Sorted Arrays](https://leetcode.com/problems/median-of-two-sorted-arrays/)

**Skills:** partitioning, pivot selection, expected linear time.

---

# 4. Binary Search on Answer (Parametric D&C)

**Idea:** Instead of dividing the array, divide the *answer space*.

**Why it shows up:** Google LOVES this pattern.

**Problems:**

* [Split Array Largest Sum](https://leetcode.com/problems/split-array-largest-sum/)
* [K-th Smallest Pair Distance](https://leetcode.com/problems/find-k-th-smallest-pair-distance/)
* [Allocate Mailboxes](https://leetcode.com/problems/allocate-mailboxes/)

**Skills:** feasibility function design, monotonicity reasoning.

---

# 5. D&C on Trees (Node as Divide Point)

**Idea:** A tree node naturally divides the tree into independent subtrees.

**Why it shows up:** Classic structural recursion.

**Problems:**

* [Binary Tree Maximum Path Sum](https://leetcode.com/problems/binary-tree-maximum-path-sum/)
* Tree Diameter (conceptual - not a direct LC problem)

**Skills:** subtree aggregation, combining child results, path splitting around node.

---

**Rule of thumb:** In interviews ask yourself - *do I split by mid, by pivot, by bad elements, or by answer space?* One of these almost always fits.
