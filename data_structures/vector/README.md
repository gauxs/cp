# Vector

## Overview

Dynamic contiguous array - the default resizable sequence in C++. Random access is $O(1)$; append amortized $O(1)$; insert/erase in the middle is $O(N)$.

In C++ the standard-library type is **`std::vector`**. See the **Library** tab for API quick reference.
