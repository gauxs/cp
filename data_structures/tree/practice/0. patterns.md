# Binary Tree Patterns Cheat Sheet

## Pattern: Tree DFS

**Use when:** A node's answer depends on information returned by its subtrees or on the current root-to-node path.

**Pattern:** Recurse into children, then return or combine a precisely defined subtree result.

**Key insight:** The recursive contract turns a whole subtree into one value or state.

### Key skills

- Preorder versus postorder placement
- Pass path state downward and return aggregates upward
- Maintain a separate global answer when the best path may cross a node

## Pattern: Tree BFS by Level

**Use when:** Output or connect nodes by depth, or select a value from each visible level.

**Pattern:** Process exactly the queue size captured at the start of each level.

**Key insight:** The queue contains the current frontier in level order.

### Key skills

- Snapshot level size
- Track first or last node per level
- Connect adjacent nodes without crossing level boundaries
