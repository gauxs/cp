# Binary Search Tree Patterns Cheat Sheet

## Pattern: Exploit BST Ordering

**Use when:** A tree guarantees ordered subtrees and the task asks for validation, search, rank, ancestry, repair, or deletion.

**Pattern:** Use bounds, inorder order, or key comparisons to avoid treating the structure as an arbitrary binary tree.

**Key insight:** Every node inherits constraints from all ancestors, while inorder traversal exposes global sorted order.

### Key skills

- Carry open lower and upper bounds
- Stop inorder traversal at a requested rank
- Handle predecessor and successor replacement
