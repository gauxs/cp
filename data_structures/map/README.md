# Map

## Overview

Associative key-value containers. `std::map` keeps keys sorted ($O(\log N)$); `std::unordered_map` is hash-based (average $O(1)$).

In C++ the standard-library type is **`std::map / std::unordered_map`**. See the **Library** tab for API quick reference.
