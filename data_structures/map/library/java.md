# Map - `HashMap` / `TreeMap`

```java
Map<Integer, String> hashMap = new HashMap<>();
hashMap.put(5, "five");
hashMap.put(1, "one");

Map<Integer, String> treeMap = new TreeMap<>();
treeMap.put(5, "five");
treeMap.put(1, "one"); // iterated in sorted key order
```
