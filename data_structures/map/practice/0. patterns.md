# Map Patterns Cheat Sheet

## Pattern: Hash Lookup

**Use when:** Membership, complements, deduplication, or grouping must be tracked while scanning.

**Pattern:** Store each value or canonical key in a hash set or hash map.

**Key insight:** Replace repeated searching with average $O(1)$ lookup.

### Key skills

- Choose a stable canonical key
- Distinguish a set from a frequency map
- Check before insert when the current element must not match itself
