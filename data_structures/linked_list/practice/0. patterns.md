# Linked List Patterns Cheat Sheet

## Pattern: Fast and Slow Pointers

**Use when:** A linked-list position depends on relative speed, distance, or cycle structure.

**Pattern:** Advance two pointers at different speeds or maintain a fixed gap between them.

**Key insight:** Relative movement exposes the midpoint, a cycle, or a node measured from the end without storing nodes.

### Key skills

- Prove cycle-entry convergence
- Create an exact pointer gap
- Split and restore a list when checking a palindrome

## Pattern: Pointer Rewiring

**Use when:** Nodes must be merged, swapped, reversed in a range, or copied with additional links.

**Pattern:** Use dummy boundaries and update a small, explicit set of links per step.

**Key insight:** Preserve every node that remains reachable before overwriting a link.

### Key skills

- Dummy-head manipulation
- Reverse a fixed-size group
- Separate node creation from random-pointer connection
