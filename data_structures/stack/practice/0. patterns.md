# Stack Patterns Cheat Sheet

## Pattern: Matching and Nested Structure

**Use when:** Closing tokens must match the most recent unmatched opening token, or nested content must be completed inside out.

**Pattern:** Push unfinished context and resolve it when its matching closer appears.

**Key insight:** Nesting is last-in-first-out: the innermost unfinished structure completes first.

### Key skills

- Map closing delimiters to opening delimiters
- Store partial counts or strings with each nested level
- Remove unmatched tokens without losing original order

## Pattern: Expression and Path Evaluation

**Use when:** Operators, operands, or path components must be resolved in last-in-first-out order.

**Pattern:** Push values or pending operators and reduce them when enough context is available.

**Key insight:** A stack makes evaluation order explicit without repeatedly rescanning the input.

### Key skills

- Parse signed and multi-digit values
- Preserve operand order for subtraction and division
- Normalize special path components
