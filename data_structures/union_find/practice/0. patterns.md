# Disjoint Set Union Patterns Cheat Sheet

## Pattern: Dynamic Connectivity

**Use when:** Elements are repeatedly connected and queries depend only on component membership.

**Pattern:** Give each component a representative; union representatives and compress paths during find.

**Key insight:** The internal tree shape is irrelevant, so path compression and union by size can flatten it safely.

### Key skills

- Count successful unions
- Track component count or size
- Sort edges when connectivity has priorities or restrictions
