# Trie Patterns Cheat Sheet

## Pattern: Prefix Index

**Use when:** Operations repeatedly insert, search, aggregate, or suggest strings by prefix.

**Pattern:** Walk one trie edge per character and store the state needed at prefix nodes.

**Key insight:** Shared prefixes are represented once and reused by every matching word.

### Key skills

- Separate prefix existence from complete-word existence
- Store aggregates or top suggestions at nodes
- Prune dead branches when deletion is useful

## Pattern: Trie-Pruned Search

**Use when:** Many dictionary words must be matched while exploring a shared state space.

**Pattern:** Carry a trie node through DFS and stop whenever the path is not a dictionary prefix.

**Key insight:** Prefix rejection prunes all words below that failed path at once.

### Key skills

- Mark and restore visited cells
- Deduplicate found words
- Remove exhausted trie branches
