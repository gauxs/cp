# Bit Manipulation Patterns Cheat Sheet

## Pattern: XOR Cancellation

**Use when:** Values occur in canceling pairs and one value or bit pattern remains.

**Pattern:** XOR all values, or partition values by a distinguishing bit before XOR.

**Key insight:** `x ^ x = 0` and XOR is associative and commutative.

### Key skills

- Isolate a distinguishing set bit
- Understand per-bit occurrence counts when values appear three times

### Problems

1. [Single Number](https://leetcode.com/problems/single-number/)
2. [Single Number II](https://leetcode.com/problems/single-number-ii/)
3. [Missing Number](https://leetcode.com/problems/missing-number/)

## Pattern: Bitwise Counting and Transformation

**Use when:** Count set bits or transform a fixed-width binary representation.

**Pattern:** Clear the lowest set bit, reuse a smaller subproblem, or move bits one position at a time.

**Key insight:** A number differs from a previously solved number by a predictable bit operation.

### Key skills

- Clear the lowest set bit
- Use unsigned shifts
- Respect fixed-width leading zeros

### Problems

1. [Number of 1 Bits](https://leetcode.com/problems/number-of-1-bits/)
2. [Counting Bits](https://leetcode.com/problems/counting-bits/)
3. [Reverse Bits](https://leetcode.com/problems/reverse-bits/)
