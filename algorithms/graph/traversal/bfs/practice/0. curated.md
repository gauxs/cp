# Breadth-First Search Patterns Cheat Sheet

## Pattern: Multi-Source and Shortest-Level BFS

**Use when:** Unweighted distance, simultaneous spreading, or minimum moves determine the answer.

**Pattern:** Enqueue the initial frontier, mark states when enqueued, and expand one edge per level.

**Key insight:** The first BFS visit reaches a state using the fewest unweighted edges.

### Key skills

- Seed multiple sources at distance zero
- Mark visited before enqueueing
- Track level boundaries or distances

### Problems

1. [Rotting Oranges](https://leetcode.com/problems/rotting-oranges/)
2. [Shortest Path in Binary Matrix](https://leetcode.com/problems/shortest-path-in-binary-matrix/)
3. [01 Matrix](https://leetcode.com/problems/01-matrix/)

## Pattern: Stateful Shortest-Path BFS

**Use when:** The shortest route depends on extra information beyond position (visited set, keys, remaining moves).

**Pattern:** Treat each queue entry as `(cell or node, state)`; mark `(position, state)` visited; expand neighbors with updated state.

**Key insight:** Unweighted BFS still gives minimum steps if every transition costs one and the state space is finite.

### Key skills

- Encode state with bitmasks or small tuples
- Distinguish revisiting a cell with a better state from useless repeats
- Build implicit neighbors (graph edges, grid moves, or lock digits)

### Problems

1. [Shortest Path Visiting All Nodes](https://leetcode.com/problems/shortest-path-visiting-all-nodes/)
2. [Shortest Path to Get All Keys](https://leetcode.com/problems/shortest-path-to-get-all-keys/)

## Pattern: Bidirectional BFS

**Use when:** An unweighted search has known start and target states, and ordinary BFS explores too many intermediate states.

**Pattern:** Run BFS from both ends and expand the smaller frontier until the searches meet.

**Key insight:** Two searches of roughly half the depth can visit far fewer states than one search across the full depth.

### Key skills

- Generate neighbors in an implicit graph
- Maintain separate visited sets for both directions
- Always expand the smaller frontier

### Problems

1. [Word Ladder](https://leetcode.com/problems/word-ladder/)
2. [Open the Lock](https://leetcode.com/problems/open-the-lock/)
