# BFS Patterns

## Pattern 1: Basic BFS Traversal
**Key Insight**: Level-by-level exploration using queue
**Problems**:
1. [Binary Tree Level Order Traversal](https://leetcode.com/problems/binary-tree-level-order-traversal/)
2. [Binary Tree Zigzag Level Order Traversal](https://leetcode.com/problems/binary-tree-zigzag-level-order-traversal/)
3. [N-ary Tree Level Order Traversal](https://leetcode.com/problems/n-ary-tree-level-order-traversal/)

**Key Skills**: Queue management, level tracking

## Pattern 2: Shortest Path in Unweighted Graph
**Key Insight**: BFS guarantees shortest path in unweighted graphs
**Problems**:
1. [Rotting Oranges](https://leetcode.com/problems/rotting-oranges/)
2. [01 Matrix](https://leetcode.com/problems/01-matrix/)
3. [Shortest Path in Binary Matrix](https://leetcode.com/problems/shortest-path-in-binary-matrix/)

**Key Skills**: Distance tracking, multi-source BFS

## Pattern 3: Connected Components
**Key Insight**: BFS explores all reachable vertices from a source
**Problems**:
1. [Number of Islands](https://leetcode.com/problems/number-of-islands/)
2. [Number of Provinces](https://leetcode.com/problems/number-of-provinces/)
3. [Max Area of Island](https://leetcode.com/problems/max-area-of-island/)

**Key Skills**: Visited array, component counting

## Pattern 4: Multi-Source BFS
**Key Insight**: Start BFS from multiple sources simultaneously
**Problems**:
1. [Rotting Oranges](https://leetcode.com/problems/rotting-oranges/)
2. [01 Matrix](https://leetcode.com/problems/01-matrix/)
3. [As Far from Land as Possible](https://leetcode.com/problems/as-far-from-land-as-possible/)

**Key Skills**: Multiple queue initialization, simultaneous processing

## Pattern 5: BFS with State
**Key Insight**: Include additional state information in BFS
**Problems**:
1. [Minimum Operations to Convert Number](https://leetcode.com/problems/minimum-operations-to-convert-number/)
2. [K Similar Strings](https://leetcode.com/problems/k-similar-strings/)
3. [Couples Holding Hands](https://leetcode.com/problems/couples-holding-hands/)

**Key Skills**: State representation, custom queue elements
