# DFS Patterns Cheat Sheet

## 1. Basic Graph Traversal
**Explore all vertices and edges.**  
**Pattern:** Recursive or stack-based traversal  
**Key Insight:** Visit all reachable vertices from source

**Problems:**  
1. [Number of Islands](https://leetcode.com/problems/number-of-islands/)  
2. [Number of Provinces](https://leetcode.com/problems/number-of-provinces/)  
3. [Number of Enclaves](https://leetcode.com/problems/number-of-enclaves/)  

**Key Skills:** recursion, visited tracking, component counting  

---

## 2. Backtracking / Path Finding
**Explore all possible paths with backtracking.**  
**Pattern:** DFS with state restoration  
**Key Insight:** Try all possibilities, backtrack on failure

**Problems:**  
1. [Word Search](https://leetcode.com/problems/word-search/)  
2. [Word Search II](https://leetcode.com/problems/word-search-ii/)  
3. [All Paths From Source to Target](https://leetcode.com/problems/all-paths-from-source-to-target/)  

**Key Skills:** backtracking, state management, path construction  

---

## 3. Connected Components
**Find all connected components in graph.**  
**Pattern:** DFS from each unvisited vertex  
**Key Insight:** Each DFS call finds one complete component

**Problems:**  
1. [Number of Connected Components in an Undirected Graph](https://leetcode.com/problems/number-of-connected-components-in-an-undirected-graph/)  
2. [Number of Islands](https://leetcode.com/problems/number-of-islands/)  
3. [Number of Provinces](https://leetcode.com/problems/number-of-provinces/)  

**Key Skills:** component identification, connected graph analysis  

---

## 4. Matrix DFS / Grid Traversal
**DFS on 2D grids.**  
**Pattern:** 4-directional or 8-directional traversal  
**Key Insight:** Treat grid cells as graph vertices

**Problems:**  
1. [Number of Islands](https://leetcode.com/problems/number-of-islands/)  
2. [Word Search](https://leetcode.com/problems/word-search/)  
3. [Number of Enclaves](https://leetcode.com/problems/number-of-enclaves/)  

**Key Skills:** grid navigation, boundary checking, 2D visited tracking  

---

## 5. Hybrid / Advanced DFS
**Combines multiple patterns - favorite for deep interviews**

**Examples:**  
1. [Word Search II](https://leetcode.com/problems/word-search-ii/) - DFS + Backtracking + Trie + Grid Traversal  
2. [All Paths From Source to Target](https://leetcode.com/problems/all-paths-from-source-to-target/) - DFS + Path Construction + Backtracking  
3. [Number of Enclaves](https://leetcode.com/problems/number-of-enclaves/) - DFS + Boundary Marking + Component Counting
