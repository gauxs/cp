# Depth-First Search Patterns Cheat Sheet

## Pattern: Flood Fill and Components

**Use when:** Connected cells or vertices must be marked, measured, or classified.

**Pattern:** Start DFS from each unvisited candidate and consume its entire component.

**Key insight:** Once a component is fully visited, it can be summarized and never explored again.

### Key skills

- Define valid neighbors
- Mark before recursing
- Accumulate size and boundary properties

### Problems

1. [Number of Islands](https://leetcode.com/problems/number-of-islands/)
2. [Max Area of Island](https://leetcode.com/problems/max-area-of-island/)
3. [Flood Fill](https://leetcode.com/problems/flood-fill/)
4. [Number of Closed Islands](https://leetcode.com/problems/number-of-closed-islands/)

## Pattern: Bridges and Critical Connections (Tarjan)

**Use when:** An undirected graph must expose edges whose removal increases the number of connected components.

**Pattern:** DFS while tracking discovery time and low-link values; an edge to a tree child is a bridge when the child's low-link is greater than the parent's discovery time.

**Key insight:** Back edges raise low-link values; tree edges that cannot reach an ancestor via any other path are critical.

### Key skills

- Maintain `disc`, `low`, and parent edge per vertex
- Skip the immediate parent in undirected DFS
- Collect tree edges that satisfy the bridge condition

### Problems

1. [Critical Connections in a Network](https://leetcode.com/problems/critical-connections-in-a-network/)

## Pattern: Strongly Connected Components (Kosaraju)

**Use when:** A directed graph must be split into maximal groups where every vertex can reach every other vertex in the same group.

**Pattern:** Run DFS on the original graph to record finish order, reverse all edges, then DFS again in reverse finish order to collect each component.

**Key insight:** Kosaraju uses two straightforward DFS passes; Tarjan finds SCCs in one pass with low-link values but is harder to implement.

### Key skills

- Build the transpose graph
- Pop finish order from a stack for the second pass
- Treat each unvisited pop as the seed of one SCC

### Problems

1. [Longest Cycle in a Graph](https://leetcode.com/problems/longest-cycle-in-a-graph/)
