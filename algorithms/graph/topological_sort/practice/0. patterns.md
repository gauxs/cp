# Topological Sort Patterns Cheat Sheet

## 1. Basic Topological Sort
**Order vertices by dependencies.**  
**Pattern:** DFS with post-order recording or BFS with in-degree tracking  
**Key Insight:** Only works on DAGs (no cycles)

**Problems:**  
1. [Course Schedule](https://leetcode.com/problems/course-schedule/)  
2. [Course Schedule II](https://leetcode.com/problems/course-schedule-ii/)  

**Key Skills:** DFS/BFS traversal, dependency tracking, cycle detection  

---

## 2. Dependency Resolution
**Resolve complex dependencies with multiple constraints.**  
**Pattern:** Multi-level topological sort with grouping  
**Key Insight:** Handle both inter-group and intra-group dependencies

**Problems:**  
1. [Sort Items by Groups Respecting Dependencies](https://leetcode.com/problems/sort-items-by-groups-respecting-dependencies/)  
2. [Alien Dictionary](https://leetcode.com/problems/alien-dictionary/)  

**Key Skills:** complex dependency handling, multi-level sorting, constraint satisfaction  

---

## 3. Lexicographic Ordering
**Find specific topological order based on constraints.**  
**Pattern:** Use priority queue/min-heap for BFS to maintain lexicographic order  
**Key Insight:** Among valid orderings, choose smallest lexicographically

**Problems:**  
1. [Alien Dictionary](https://leetcode.com/problems/alien-dictionary/)  

**Key Skills:** custom ordering, priority-based BFS, lexicographic comparison  

---

## 4. Hybrid / Advanced Topological Sort
**Combines multiple patterns - favorite for deep interviews**

**Examples:**  
1. [Sort Items by Groups Respecting Dependencies](https://leetcode.com/problems/sort-items-by-groups-respecting-dependencies/) - Multi-level Topo Sort + Cycle Detection + Dependency Resolution  
2. [Alien Dictionary](https://leetcode.com/problems/alien-dictionary/) - Graph Construction + Topo Sort + Lexicographic Order  
3. [Course Schedule II](https://leetcode.com/problems/course-schedule-ii/) - Cycle Detection + Topological Sort + Dependency Resolution
