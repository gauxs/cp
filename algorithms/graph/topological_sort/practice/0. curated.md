# Topological Sort Patterns Cheat Sheet

## Pattern: Dependency Ordering

**Use when:** Directed prerequisites constrain a valid processing order or reveal impossible cycles.

**Pattern:** Build indegrees, enqueue zero-indegree nodes, and remove outgoing dependencies.

**Key insight:** A DAG always exposes at least one currently dependency-free vertex.

### Key skills

- Build edges in the correct direction
- Compare processed count with vertex count
- Reverse edges when terminal states should be processed first
