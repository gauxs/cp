# Minimum Spanning Tree Patterns Cheat Sheet

## Pattern: Minimum Spanning Connectivity

**Use when:** All vertices must be connected with minimum total edge cost.

**Pattern:** Apply Kruskal with DSU or Prim with a priority queue.

**Key insight:** The lightest edge crossing a cut is safe for some MST.

### Key skills

- Generate implicit graph edges
- Add a virtual node to model an alternative connection
- Test critical edges by excluding or forcing them

1. [Min Cost to Connect All Points](https://leetcode.com/problems/min-cost-to-connect-all-points/)
2. [Connecting Cities With Minimum Cost](https://leetcode.com/problems/connecting-cities-with-minimum-cost/)
3. [Optimize Water Distribution in a Village](https://leetcode.com/problems/optimize-water-distribution-in-a-village/)

## Pattern: Minimax Connectivity

**Use when:** Minimize the largest edge or maximize the smallest edge along a connecting path.

**Pattern:** Process edges in threshold order until the endpoints become connected.

**Key insight:** MST paths preserve the optimal bottleneck value between vertices.

### Key skills

- Sort cells or edges by threshold
- Recognize minimum-maximum versus maximum-minimum objectives

### Problems

1. [Swim in Rising Water](https://leetcode.com/problems/swim-in-rising-water/)
2. [Path With Maximum Minimum Value](https://leetcode.com/problems/path-with-maximum-minimum-value/)
