# Shortest Path Patterns Cheat Sheet

## Pattern: Weighted Shortest Path

**Use when:** Edge weights define the best path and states may be finalized or relaxed by increasing distance.

**Pattern:** Choose Dijkstra, Bellman-Ford, or Floyd-Warshall according to weight signs, constraints, and source count.

**Key insight:** The relaxation rule stays the same; graph properties determine the safe processing order.

### Key skills

- Reject stale priority-queue entries
- Expand state when stops or other constraints matter
- Change the path-combination operator for probability or minimax cost

1. [Network Delay Time](https://leetcode.com/problems/network-delay-time/)
2. [Path with Maximum Probability](https://leetcode.com/problems/path-with-maximum-probability/)

## Pattern: 0-1 BFS

**Use when:** Every edge has weight zero or one.

**Pattern:** Use a deque; push zero-cost transitions to the front and one-cost transitions to the back.

**Key insight:** The deque keeps states ordered by distance without the logarithmic overhead of a priority queue.

### Key skills

- Recognize binary transition costs hidden in grid rules
- Relax distances before adding states to the deque
- Reprocess a state only when its distance improves

### Problems

1. [Minimum Obstacle Removal to Reach Corner](https://leetcode.com/problems/minimum-obstacle-removal-to-reach-corner/)
2. [Minimum Cost to Make at Least One Valid Path in a Grid](https://leetcode.com/problems/minimum-cost-to-make-at-least-one-valid-path-in-a-grid/)

## Pattern: Bounded-Edge Bellman-Ford

**Use when:** The path may use only a bounded number of edges or stops.

**Pattern:** Relax every edge from the previous iteration's distances; run one iteration per allowed edge.

**Key insight:** Copying the distance array prevents one iteration from accidentally using more than one new edge.

### Key skills

- Separate previous and current iteration distances
- Run one relaxation round per allowed edge
- Convert at most `K` stops into at most `K + 1` edges

### Problems

1. [Cheapest Flights Within K Stops](https://leetcode.com/problems/cheapest-flights-within-k-stops/)
