# Shortest Path Patterns Cheat Sheet

## Pattern: Weighted Shortest Path

**Use when:** Edge weights define the best path and states may be finalized or relaxed by increasing distance.

**Pattern:** Choose Dijkstra, Bellman-Ford, or Floyd-Warshall according to weight signs, constraints, and source count.

**Key insight:** The relaxation rule stays the same; graph properties determine the safe processing order.

### Key skills

- Reject stale priority-queue entries
- Expand state when stops or other constraints matter
- Change the path-combination operator for probability or minimax cost
