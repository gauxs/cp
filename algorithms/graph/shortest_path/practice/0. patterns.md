# Shortest Path Patterns Cheat Sheet

## 1. Single Source Shortest Path (Dijkstra)
**Find shortest paths from one source to all vertices.**  
**Pattern:** Greedy algorithm with priority queue  
**Key Insight:** Works only with non-negative edge weights

**Problems:**  
1. [Network Delay Time](https://leetcode.com/problems/network-delay-time/)  
2. [Path with Maximum Probability](https://leetcode.com/problems/path-with-maximum-probability/)  
3. [Cheapest Flights Within K Stops](https://leetcode.com/problems/cheapest-flights-within-k-stops/)  

**Key Skills:** priority queue, greedy selection, edge relaxation  

---

## 2. Negative Edge Weights (Bellman-Ford)
**Handle graphs with negative edge weights.**  
**Pattern:** Relax all edges V-1 times  
**Key Insight:** Can detect negative weight cycles

**Problems:**  
1. [Network Delay Time](https://leetcode.com/problems/network-delay-time/)  
2. [Cheapest Flights Within K Stops](https://leetcode.com/problems/cheapest-flights-within-k-stops/)  

**Key Skills:** edge relaxation, negative cycle detection, dynamic programming  

---

## 3. All Pairs Shortest Path (Floyd-Warshall)
**Find shortest paths between all pairs of vertices.**  
**Pattern:** Dynamic programming with intermediate vertices  
**Key Insight:** Works with negative edges, detects negative cycles

**Problems:**  
1. [Find the City With the Smallest Number of Neighbors at a Threshold Distance](https://leetcode.com/problems/find-the-city-with-the-smallest-number-of-neighbors-at-a-threshold-distance/)  

**Key Skills:** dynamic programming, all-pairs computation, negative cycle detection  

---

## 4. 0-1 BFS / Binary Edge Weights
**Optimize for graphs with 0 and 1 edge weights.**  
**Pattern:** Deque-based BFS (0-weight edges to front, 1-weight to back)  
**Key Insight:** O(V + E) instead of O(E log V)

**Problems:**  
1. [Minimum Obstacles to Remove to Reach Corner](https://leetcode.com/problems/minimum-obstacle-removal-to-reach-corner/)  
2. [Shortest Path in Binary Matrix](https://leetcode.com/problems/shortest-path-in-binary-matrix/)  

**Key Skills:** deque manipulation, edge weight optimization, BFS variants  

---

## 5. Modified Shortest Path with Constraints
**Shortest path with additional constraints.**  
**Pattern:** Modified Dijkstra/Bellman-Ford with state tracking  
**Key Insight:** Track additional state (k stops, effort, etc.)

**Problems:**  
1. [Cheapest Flights Within K Stops](https://leetcode.com/problems/cheapest-flights-within-k-stops/)  
2. [Path With Minimum Effort](https://leetcode.com/problems/path-with-minimum-effort/)  
3. [Path with Maximum Probability](https://leetcode.com/problems/path-with-maximum-probability/)  

**Key Skills:** state space expansion, constraint handling, modified relaxation  

---

## 6. Hybrid / Advanced Shortest Path
**Combines multiple patterns - favorite for deep interviews**

**Examples:**  
1. [Cheapest Flights Within K Stops](https://leetcode.com/problems/cheapest-flights-within-k-stops/) - Modified Bellman-Ford + K Constraint + DP  
2. [Path With Minimum Effort](https://leetcode.com/problems/path-with-minimum-effort/) - Binary Search + Dijkstra + MinMax Path  
3. [Network Delay Time](https://leetcode.com/problems/network-delay-time/) - Dijkstra + All Reachable + Time Calculation
