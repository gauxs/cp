# Bipartite Graph Patterns Cheat Sheet

## Pattern: Two-Coloring

**Use when:** Pairwise constraints require adjacent or conflicting entities to belong to opposite groups.

**Pattern:** Traverse every component with BFS or DFS, assigning each neighbor the opposite color.

**Key insight:** A graph is bipartite exactly when it contains no odd-length cycle.

### Key skills

- Start traversal from every uncolored component
- Detect a same-color edge immediately
- Build a graph from implicit conflict rules
