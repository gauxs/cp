# Bipartite Graph Patterns Cheat Sheet

## 1. Two-Coloring Pattern
**The fundamental bipartite check.**  
**Pattern:** DFS/BFS traversal with alternating colors  
**Key Insight:** Graph is bipartite if and only if two-colorable if and only if no odd cycles

**Problems:**  
1. [Is Graph Bipartite?](https://leetcode.com/problems/is-graph-bipartite/)  
2. [Possible Bipartition](https://leetcode.com/problems/possible-bipartition/)  
3. [Divide Array Into Equal Pairs](https://leetcode.com/problems/divide-array-into-equal-pairs/)  

**Key Skills:** DFS/BFS coloring, conflict detection, component handling  

---

## 2. Graph Partitioning / Two-Set Problems
**Divide vertices into two distinct sets.**  
**Pattern:** Model problem as bipartite graph construction  
**Key Insight:** Many problems have hidden bipartite structure

**Problems:**  
1. [Divide Array Into Equal Pairs](https://leetcode.com/problems/divide-array-into-equal-pairs/)  
2. [Possible Bipartition](https://leetcode.com/problems/possible-bipartition/)  

**Key Skills:** problem modeling, graph construction, constraint mapping  

---

## 3. Constraint Satisfaction / Coloring
**Satisfy constraints between two groups.**  
**Pattern:** Model constraints as edges, check bipartite property  
**Key Insight:** Constraint satisfaction often reduces to bipartite checking

**Problems:**  
1. [Possible Bipartition](https://leetcode.com/problems/possible-bipartition/)  
2. [Is Graph Bipartite?](https://leetcode.com/problems/is-graph-bipartite/)  

**Key Skills:** constraint modeling, conflict detection, satisfaction checking  

---

## 4. Hidden Bipartite Structure
**Problems that don't look bipartite but are.**  
**Pattern:** Identify two distinct groups in the problem  
**Key Insight:** Many problems have implicit bipartite structure

**Problems:**  
1. [Divide Array Into Equal Pairs](https://leetcode.com/problems/divide-array-into-equal-pairs/)  
2. [Meeting Rooms II](https://leetcode.com/problems/meeting-rooms-ii/)  

**Key Skills:** problem analysis, structure identification, model transformation  

---

## 5. Hybrid / Advanced Bipartite
**Combines multiple patterns - favorite for deep interviews**

**Examples:**  
1. [Possible Bipartition](https://leetcode.com/problems/possible-bipartition/) - Constraint Modeling + Two-Coloring + Component Handling  
2. [Divide Array Into Equal Pairs](https://leetcode.com/problems/divide-array-into-equal-pairs/) - Hidden Structure + Graph Construction + Bipartite Checking  
3. [Is Graph Bipartite?](https://leetcode.com/problems/is-graph-bipartite/) - Two-Coloring + Cycle Detection + Component Handling
