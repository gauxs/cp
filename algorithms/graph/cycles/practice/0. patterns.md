# Cycle Detection Patterns Cheat Sheet

## 1. Direct Cycle Detection
**The fundamental cycle check.**  
**Pattern:** DFS with color tracking (WHITE/GRAY/BLACK)  
**Key Insight:** Back edge to GRAY vertex indicates cycle

**Problems:**  
1. [Course Schedule](https://leetcode.com/problems/course-schedule/)  
2. [Graph Valid Tree](https://leetcode.com/problems/graph-valid-tree/)  
3. [Linked List Cycle](https://leetcode.com/problems/linked-list-cycle/)  

**Key Skills:** DFS coloring, back edge detection, recursion stack tracking  

---

## 2. Cycle Detection + Topological Sort
**Detect cycle and build topological order.**  
**Pattern:** DFS cycle detection with result array  
**Key Insight:** Only acyclic graphs can be topologically sorted

**Problems:**  
1. [Course Schedule II](https://leetcode.com/problems/course-schedule-ii/)  
2. [Alien Dictionary](https://leetcode.com/problems/alien-dictionary/)  
3. [Sort Items by Groups Respecting Dependencies](https://leetcode.com/problems/sort-items-by-groups-respecting-dependencies/)  

**Key Skills:** topological ordering, dependency resolution, cycle prevention  

---

## 3. Find Cycle-Causing Edge
**Identify specific edge that creates cycle.**  
**Pattern:** Remove edges and test for cycle disappearance  
**Key Insight:** Union-Find or DFS to find redundant connections

**Problems:**  
1. [Redundant Connection](https://leetcode.com/problems/redundant-connection/)  
2. [Redundant Connection II](https://leetcode.com/problems/redundant-connection-ii/)  
3. [Find the Duplicate Number](https://leetcode.com/problems/find-the-duplicate-number/)  

**Key Skills:** edge removal, union-find, cycle isolation  

---

## 4. Array as Graph (Floyd's Algorithm)
**Treat array indices as graph edges.**  
**Pattern:** Slow and fast pointer technique  
**Key Insight:** Array values point to indices, creating implicit graph

**Problems:**  
1. [Find the Duplicate Number](https://leetcode.com/problems/find-the-duplicate-number/)  
2. [Linked List Cycle II](https://leetcode.com/problems/linked-list-cycle-ii/)  
3. [Happy Number](https://leetcode.com/problems/happy-number/)  

**Key Skills:** two-pointer technique, cycle detection in sequences  

---

## 5. Negative Weight Cycle Detection
**Find cycles with negative total weight.**  
**Pattern:** Bellman-Ford or Floyd-Warshall algorithm  
**Key Insight:** Relax edges V-1 times, then check for further relaxation

**Problems:**  
1. [Network Delay Time](https://leetcode.com/problems/network-delay-time/)  
2. [Cheapest Flights Within K Stops](https://leetcode.com/problems/cheapest-flights-within-k-stops/)  
3. [Path With Minimum Effort](https://leetcode.com/problems/path-with-minimum-effort/)  

**Key Skills:** edge relaxation, negative cycle detection, shortest path algorithms  

---

## 6. Grid/Matrix Cycle Detection
**Detect cycles in 2D grid structures.**  
**Pattern:** DFS with visited tracking and parent tracking  
**Key Insight:** Avoid revisiting parent, detect back edges in grid

**Problems:**  
1. [Detect Cycles in 2D Grid](https://leetcode.com/problems/detect-cycles-in-2d-grid/)  
2. [Word Search](https://leetcode.com/problems/word-search/)  
3. [Word Search II](https://leetcode.com/problems/word-search-ii/)  

**Key Skills:** grid traversal, parent tracking, 2D cycle detection  

---

## 7. Hybrid / Advanced Cycle Detection
**Combines multiple patterns - favorite for deep interviews**

**Examples:**  
1. [Course Schedule II](https://leetcode.com/problems/course-schedule-ii/) - Cycle Detection + Topological Sort + Dependency Resolution  
2. [Redundant Connection II](https://leetcode.com/problems/redundant-connection-ii/) - Directed Graph + Edge Removal + Cycle Detection  
3. [Find the Duplicate Number](https://leetcode.com/problems/find-the-duplicate-number/) - Array as Graph + Floyd's Algorithm + Cycle Detection
