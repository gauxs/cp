# Cycle Detection Patterns Cheat Sheet

## Pattern: DFS Cycle Detection

**Use when:** A directed or undirected graph must be checked for a cycle or a cycle must be reconstructed.

**Pattern:** Track the active recursion path in directed graphs; in undirected graphs, ignore only the edge back to the parent.

**Key insight:** Revisiting an active ancestor forms a cycle, while revisiting a fully processed directed vertex does not.

### Key skills

- Distinguish visited from currently active
- Carry parent edges in undirected graphs
- Reconstruct a cycle using parent pointers

## Pattern: Functional Graph Cycle

**Use when:** Every state has exactly one next state, forming chains that may enter cycles.

**Pattern:** Apply slow and fast pointers, then reason from their meeting point.

**Key insight:** Different pointer speeds must meet inside a finite reachable cycle.

### Key skills

- Model values as next-state links
- Separate cycle existence from cycle-entry recovery

### Problems

1. [Find the Duplicate Number](https://leetcode.com/problems/find-the-duplicate-number/)
