# Binary Search Patterns Cheat Sheet

## 1. Standard Binary Search on Sorted Array
**Find target in sorted array.**  
**Pattern:** Classic binary search with low/high pointers  
**Key Insight:** Eliminate half of search space at each step

**Problems:**  
1. [Binary Search](https://leetcode.com/problems/binary-search/)  
2. [Search Insert Position](https://leetcode.com/problems/search-insert-position/)  
3. [Find First and Last Position of Element in Sorted Array](https://leetcode.com/problems/find-first-and-last-position-of-element-in-sorted-array/)  

**Key Skills:** boundary initialization, mid calculation, avoiding infinite loops  

---

## 2. Binary Search on Answer (Search Space)
**Find optimal value that satisfies a condition.**  
**Pattern:** Binary search on the answer space, not the array  
**Key Insight:** If condition(k) is True, then condition(>k) is True (monotonicity)

**Problems:**  
1. [Capacity To Ship Packages Within D Days](https://leetcode.com/problems/capacity-to-ship-packages-within-d-days/)  
2. [Koko Eating Bananas](https://leetcode.com/problems/koko-eating-bananas/)  
3. [Split Array Largest Sum](https://leetcode.com/problems/split-array-largest-sum/)  
4. [Minimum Number of Days to Make m Bouquets](https://leetcode.com/problems/minimum-number-of-days-to-make-m-bouquets/)  
5. [Ugly Number III](https://leetcode.com/problems/ugly-number-iii/)  

**Key Skills:** identifying monotonicity, defining condition function, binary search on answer range  

---

## 3. Binary Search on Matrix / 2D Space
**Find kth smallest/largest in sorted matrix or 2D space.**  
**Pattern:** Binary search on value range, count elements <= value  
**Key Insight:** Matrix rows/columns are sorted, enabling efficient counting

**Problems:**  
1. [Kth Smallest Number in Multiplication Table](https://leetcode.com/problems/kth-smallest-number-in-multiplication-table/)  
2. [Kth Smallest Element in a Sorted Matrix](https://leetcode.com/problems/kth-smallest-element-in-a-sorted-matrix/)  
3. [Find K-th Smallest Pair Distance](https://leetcode.com/problems/find-k-th-smallest-pair-distance/)  

**Key Skills:** 2D binary search, counting elements, matrix traversal optimization  

---

## 4. Binary Search with Custom Condition
**Binary search where condition is not simple comparison.**  
**Pattern:** Define custom condition function, binary search on domain  
**Key Insight:** Monotonicity in condition allows binary search

**Problems:**  
1. [Ugly Number III](https://leetcode.com/problems/ugly-number-iii/)  
2. [Capacity To Ship Packages Within D Days](https://leetcode.com/problems/capacity-to-ship-packages-within-d-days/)  

**Key Skills:** custom condition design, monotonicity verification, domain transformation  

---

## 5. Hybrid / Advanced Binary Search
**Combines multiple patterns - favorite for deep interviews**

**Examples:**  
1. [Kth Smallest Element in a Sorted Matrix](https://leetcode.com/problems/kth-smallest-element-in-a-sorted-matrix/) - Binary Search on Answer + Matrix Counting  
2. [Find K-th Smallest Pair Distance](https://leetcode.com/problems/find-k-th-smallest-pair-distance/) - Binary Search on Answer + Two Pointers  
3. [Split Array Largest Sum](https://leetcode.com/problems/split-array-largest-sum/) - Binary Search on Answer + Greedy Validation
