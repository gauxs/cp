# Quick Select Patterns Cheat Sheet

## Pattern: Partition Selection

**Use when:** The k-th ordered element or a median-based partition is needed without fully sorting the input.

**Pattern:** Partition around a pivot and continue only into the side containing the target rank.

**Key insight:** Partition fixes enough relative order to discard one side after every step.

### Key skills

- Convert k-th largest into a zero-based sorted index
- Randomize pivots to avoid consistently unbalanced partitions
- Use three-way partitioning when duplicate values matter
