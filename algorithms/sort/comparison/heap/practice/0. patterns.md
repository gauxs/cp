# Heap Sort Patterns Cheat Sheet

## Pattern: Top K with Heap

**Use when:** Need k largest/smallest or streaming order statistics.

**Pattern:** Min-heap of size k for k-th largest; max-heap for k-th smallest; two heaps for median stream.

**Key insight:** Heap gives $O(\log k)$ per insert; size-k heap yields $O(N \log k)$.

### Key skills

- min-heap vs max-heap for k-th
- two-heap median pattern
