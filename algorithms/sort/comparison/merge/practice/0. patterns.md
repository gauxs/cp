# Merge Sort Patterns Cheat Sheet

## Pattern: Merge Two Sorted Sequences

**Use when:** Combining sorted arrays/lists or the merge step of merge sort.

**Pattern:** Two pointers merge the smaller head into output; recurse on halves for a full sort.

**Key insight:** Merge of two sorted sequences is linear; recursion gives $O(N \log N)$.

### Key skills

- merge two arrays
- merge on linked lists (fast/slow split)

### Problems

1. [Merge Sorted Array](https://leetcode.com/problems/merge-sorted-array/)
2. [Sort List](https://leetcode.com/problems/sort-list/)

## Pattern: Count During Merge

**Use when:** Need inversion-style counts while sorting.

**Pattern:** During merge of two sorted halves, count how many right-half elements pair with each left-half element.

**Key insight:** Sorted halves make cross-half counts linear in the merge.

### Key skills

- inversion / reverse-pair counting in merge
- stable index mapping for “smaller after self”

### Problems

1. [Reverse Pairs](https://leetcode.com/problems/reverse-pairs/)
2. [Count of Smaller Numbers After Self](https://leetcode.com/problems/count-of-smaller-numbers-after-self/)
