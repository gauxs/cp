# Merge Sort Patterns Cheat Sheet

## Pattern: Merge Two Sorted Sequences

**Use when:** Combining sorted arrays/lists or merge-sort recursion step.

**Pattern:** Two pointers merge the smaller head into output; recurse on halves for full sort.

**Key insight:** Merge of two sorted sequences is linear; recursion gives $O(N \log N)$.

### Key skills

- merge two arrays
- merge on linked lists (fast splits)

### Problems

1. [Merge Sorted Array](https://leetcode.com/problems/merge-sorted-array/)
2. [Sort List](https://leetcode.com/problems/sort-list/)

## Pattern: Sort Then Merge Intervals

**Use when:** Interval problems after sorting by start (or end).

**Pattern:** Sort intervals, then merge overlapping in one pass.

**Key insight:** Sorting establishes a timeline for linear merge.

### Key skills

- comparator on interval start
- overlap check after sort

### Problems

1. [Merge Intervals](https://leetcode.com/problems/merge-intervals/)
2. [Meeting Rooms II](https://leetcode.com/problems/meeting-rooms-ii/)
