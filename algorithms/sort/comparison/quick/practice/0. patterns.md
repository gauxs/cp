# Quick Sort Patterns Cheat Sheet

## Pattern: Quick Sort Partition

**Use when:** Sorting in-place or selecting order via pivot placement.

**Pattern:** Pick pivot, partition so elements $\lt$ pivot are left, recurse on both sides.

**Key insight:** Partition places pivot in final position in one linear scan.

### Key skills

- pivot choice (last, random, median)
- partition invariant (two pointers or Lomuto/Hoare)

### Problems

1. [Sort an Array](https://leetcode.com/problems/sort-an-array/)
2. [Sort Colors](https://leetcode.com/problems/sort-colors/)

## Pattern: Quickselect (K-th Element)

**Use when:** Need k-th largest/smallest without full sort.

**Pattern:** Partition like quick sort; recurse only on the side containing index $k$.

**Key insight:** Only one recursive branch needed after partition.

### Key skills

- mapping k-th largest to index
- average $O(N)$ time

### Problems

1. [Kth Largest Element in an Array](https://leetcode.com/problems/kth-largest-element-in-an-array/)
