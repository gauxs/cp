# Sorting Patterns Cheat Sheet

## 1. Comparison-Based Sorting  
**The classic backbone.**  
**Algorithms:** Merge Sort, Quick Sort, Heap Sort, Insertion Sort  
**Pattern:** Divide and Conquer and Merge or Partition  

**Problems:**  
1. [Sort an Array](https://leetcode.com/problems/sort-an-array/)  
2. [Merge Sorted Array](https://leetcode.com/problems/merge-sorted-array/)  
3. [Sort Colors](https://leetcode.com/problems/sort-colors/)  
4. [Merge Intervals](https://leetcode.com/problems/merge-intervals/)  
5. [Meeting Rooms II](https://leetcode.com/problems/meeting-rooms-ii/)  

**Key Skills:** recursion, partition logic, stability, merge operation  

---

## 2. Counting / Bucket / Radix Sorting  
Used when input is **numeric and bounded**.  
**Pattern:** Count frequencies or bucket by digit/interval and Reconstruct  

**Problems:**  
1. [Sort Characters by Frequency](https://leetcode.com/problems/sort-characters-by-frequency/)  
2. [Maximum Gap](https://leetcode.com/problems/maximum-gap/)  
3. [Relative Sort Array](https://leetcode.com/problems/relative-sort-array/)  
4. [Wiggle Sort I](https://leetcode.com/problems/wiggle-sort-i/)  

**Key Skills:** cumulative counts, range mapping, O(n + k) logic  

---

## 3. Selection / Partial Sorting  
Only care about a **subset** (e.g. top-K or median).  
**Pattern:** Use Quickselect or Heap to find boundary values  

**Problems:**  
1. [Kth Largest Element in an Array](https://leetcode.com/problems/kth-largest-element-in-an-array/)  
2. [Top K Frequent Elements](https://leetcode.com/problems/top-k-frequent-elements/)  
3. [Find Median from Data Stream](https://leetcode.com/problems/find-median-from-data-stream/)  
4. [Wiggle Sort II](https://leetcode.com/problems/wiggle-sort-ii/)  

**Key Skills:** partitioning logic, heap management, balancing order vs. cost  

---

## 4. Reordering / Wiggle / Relative Sorting  
Sorting by **pattern**, not numeric value.  
**Pattern:** Sort or partially sort and rearrange indices  

**Problems:**  
1. [Wiggle Sort I](https://leetcode.com/problems/wiggle-sort-i/)  
2. [Wiggle Sort II](https://leetcode.com/problems/wiggle-sort-ii/)  
3. [Relative Sort Array](https://leetcode.com/problems/relative-sort-array/)  
4. [Reorder Data in Log Files](https://leetcode.com/problems/reorder-data-in-log-files/)  
5. [Sort Array by Parity](https://leetcode.com/problems/sort-array-by-parity/)  
6. [Sort Array by Parity II](https://leetcode.com/problems/sort-array-by-parity-ii/)  

**Key Skills:** reindexing, alternating constraints, pattern-driven swapping  

---

## 5. Counting While Sorting (Merge Variants)  
You sort and **count relationships** simultaneously.  
**Pattern:** During merge, count cross-pairs meeting a condition  

**Problems:**  
1. [Reverse Pairs](https://leetcode.com/problems/reverse-pairs/)  
2. [Count of Smaller Numbers After Self](https://leetcode.com/problems/count-of-smaller-numbers-after-self/)  
3. [Smaller Numbers Than Current](https://leetcode.com/problems/how-many-numbers-are-smaller-than-the-current-number/)  

**Key Skills:** merge logic, pointer manipulation, O(n log n) counting  

---

## 6. Custom Comparator Sorting  
Sorting driven by **logic or custom rules** (not just numeric).  
**Pattern:** Define comparator (by string, frequency, or custom rule)  

**Problems:**  
1. [Largest Number](https://leetcode.com/problems/largest-number/)  
2. [Reorder Data in Log Files](https://leetcode.com/problems/reorder-data-in-log-files/)  
3. [Meeting Rooms](https://leetcode.com/problems/meeting-rooms/)  
4. [Merge Intervals](https://leetcode.com/problems/merge-intervals/)  
5. [Sort by Bits](https://leetcode.com/problems/sort-integers-by-the-number-of-1-bits/)  

**Key Skills:** comparator design, transitivity, stability  

---

## 7. Topological / Dependency Sorting  
Not numeric — **order by dependency constraints**.  
**Pattern:** Build a graph and perform topological sort  

**Problems:**  
1. [Course Schedule II](https://leetcode.com/problems/course-schedule-ii/)  
2. [Alien Dictionary](https://leetcode.com/problems/alien-dictionary/)  
3. [Sort Items by Groups Respecting Dependencies](https://leetcode.com/problems/sort-items-by-groups-respecting-dependencies/)  

**Key Skills:** graph logic, Kahn's algorithm, recursion  

---

## 8. Spatial / Coordinate Sorting  
Sort by **multiple axes or keys**.  
**Pattern:** Sort by x then y (lexicographic / multi-key logic)  

**Problems:**  
1. [Merge Intervals](https://leetcode.com/problems/merge-intervals/)  
2. [Minimum Number of Arrows to Burst Balloons](https://leetcode.com/problems/minimum-number-of-arrows-to-burst-balloons/)  
3. [The Skyline Problem](https://leetcode.com/problems/the-skyline-problem/)  
4. [Meeting Rooms II](https://leetcode.com/problems/meeting-rooms-ii/)  

**Key Skills:** multi-key sorting, event ordering  

---

## 9. Streaming / Dynamic Sorting  
Maintain order **as data streams in**.  
**Pattern:** Use heaps or balanced structures for dynamic ordering  

**Problems:**  
1. [Find Median from Data Stream](https://leetcode.com/problems/find-median-from-data-stream/)  
2. [Kth Largest in Stream](https://leetcode.com/problems/kth-largest-element-in-a-stream/)  
3. [Sliding Window Median](https://leetcode.com/problems/sliding-window-median/)  

**Key Skills:** heap balancing, online ordering  

---

## 10. Hybrid / Trick Sorting  
Combines multiple patterns - favorite for deep interviews  

**Examples:**  
1. [Wiggle Sort II](https://leetcode.com/problems/wiggle-sort-ii/) - Selection + DNF + Reindexing  
2. [Reverse Pairs](https://leetcode.com/problems/reverse-pairs/) - Merge + Counting  
3. [Largest Number](https://leetcode.com/problems/largest-number/) - Custom Comparator + String Sort  
4. [Count of Smaller Numbers After Self](https://leetcode.com/problems/count-of-smaller-numbers-after-self/) - Merge + BST Hybrid
