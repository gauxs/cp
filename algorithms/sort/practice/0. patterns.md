# 🧩 Sorting Patterns Cheat Sheet

## 1. 🧠 Comparison-Based Sorting  
**The classic backbone.**  
**Algorithms:** Merge Sort, Quick Sort, Heap Sort, Insertion Sort  
**Pattern:** Divide → Conquer → Merge or Partition  

**Problems:**  
- [Sort an Array](https://leetcode.com/problems/sort-an-array/)  
- [Merge Sorted Array](https://leetcode.com/problems/merge-sorted-array/)  
- [Sort Colors](https://leetcode.com/problems/sort-colors/) *(small-range Quick Sort variant)*  
- [Merge Intervals](https://leetcode.com/problems/merge-intervals/) / [Meeting Rooms II](https://leetcode.com/problems/meeting-rooms-ii/)  

**Key Skills:** recursion, partition logic, stability, merge operation  

---

## 2. 🔢 Counting / Bucket / Radix Sorting  
Used when input is **numeric and bounded**.  
**Pattern:** Count frequencies or bucket by digit/interval → Reconstruct  

**Problems:**  
- [Sort Characters by Frequency](https://leetcode.com/problems/sort-characters-by-frequency/)  
- [Maximum Gap](https://leetcode.com/problems/maximum-gap/)  
- [Relative Sort Array](https://leetcode.com/problems/relative-sort-array/)  
- [Wiggle Sort I](https://leetcode.com/problems/wiggle-sort-i/) *(bucket trick)*  

**Key Skills:** cumulative counts, range mapping, O(n + k) logic  

---

## 3. 🎯 Selection / Partial Sorting  
Only care about a **subset** (e.g. top-K or median).  
**Pattern:** Use Quickselect or Heap to find boundary values  

**Problems:**  
- [Kth Largest Element in an Array](https://leetcode.com/problems/kth-largest-element-in-an-array/)  
- [Top K Frequent Elements](https://leetcode.com/problems/top-k-frequent-elements/)  
- [Find Median from Data Stream](https://leetcode.com/problems/find-median-from-data-stream/)  
- [Wiggle Sort II](https://leetcode.com/problems/wiggle-sort-ii/) *(median-based rearrangement)*  

**Key Skills:** partitioning logic, heap management, balancing order vs. cost  

---

## 4. 🔁 Reordering / Wiggle / Relative Sorting  
Sorting by **pattern**, not numeric value.  
**Pattern:** Sort or partially sort → rearrange indices  

**Problems:**  
- [Wiggle Sort I](https://leetcode.com/problems/wiggle-sort-i/) / [Wiggle Sort II](https://leetcode.com/problems/wiggle-sort-ii/)  
- [Relative Sort Array](https://leetcode.com/problems/relative-sort-array/)  
- [Reorder Data in Log Files](https://leetcode.com/problems/reorder-data-in-log-files/)  
- [Sort Array by Parity](https://leetcode.com/problems/sort-array-by-parity/) / [Sort Array by Parity II](https://leetcode.com/problems/sort-array-by-parity-ii/)  

**Key Skills:** reindexing, alternating constraints, pattern-driven swapping  

---

## 5. 🧮 Counting While Sorting (Merge Variants)  
You sort and **count relationships** simultaneously.  
**Pattern:** During merge, count cross-pairs meeting a condition  

**Problems:**  
- [Count Inversions](https://leetcode.com/problems/reverse-pairs/) *(classic inversion problem; LeetCode uses reverse pairs as variant)*  
- [Reverse Pairs](https://leetcode.com/problems/reverse-pairs/)  
- [Count of Smaller Numbers After Self](https://leetcode.com/problems/count-of-smaller-numbers-after-self/)  
- [Smaller Numbers Than Current](https://leetcode.com/problems/how-many-numbers-are-smaller-than-the-current-number/) *(simplified variant)*  

**Key Skills:** merge logic, pointer manipulation, O(n log n) counting  

---

## 6. ⚙️ Custom Comparator Sorting  
Sorting driven by **logic or custom rules** (not just numeric).  
**Pattern:** Define comparator (by string, frequency, or custom rule)  

**Problems:**  
- [Largest Number](https://leetcode.com/problems/largest-number/)  
- [Reorder Data in Log Files](https://leetcode.com/problems/reorder-data-in-log-files/)  
- [Meeting Rooms](https://leetcode.com/problems/meeting-rooms/) / [Merge Intervals](https://leetcode.com/problems/merge-intervals/) *(sorting by start time)*  
- [Sort by Bits](https://leetcode.com/problems/sort-integers-by-the-number-of-1-bits/)  

**Key Skills:** comparator design, transitivity, stability  

---

## 7. 🧭 Topological / Dependency Sorting  
Not numeric — **order by dependency constraints**.  
**Pattern:** Build a graph → perform topological sort  

**Problems:**  
- [Course Schedule II](https://leetcode.com/problems/course-schedule-ii/)  
- [Alien Dictionary](https://leetcode.com/problems/alien-dictionary/)  
- [Sort Items by Groups Respecting Dependencies](https://leetcode.com/problems/sort-items-by-groups-respecting-dependencies/)  

**Key Skills:** graph logic, Kahn’s algorithm, recursion  

---

## 8. 🌐 Spatial / Coordinate Sorting  
Sort by **multiple axes or keys**.  
**Pattern:** Sort by x then y (lexicographic / multi-key logic)  

**Problems:**  
- [Merge Intervals](https://leetcode.com/problems/merge-intervals/)  
- [Minimum Number of Arrows to Burst Balloons](https://leetcode.com/problems/minimum-number-of-arrows-to-burst-balloons/)  
- [The Skyline Problem](https://leetcode.com/problems/the-skyline-problem/)  
- [Meeting Rooms II](https://leetcode.com/problems/meeting-rooms-ii/)  

**Key Skills:** multi-key sorting, event ordering  

---

## 9. ⚡ Streaming / Dynamic Sorting  
Maintain order **as data streams in**.  
**Pattern:** Use heaps or balanced structures for dynamic ordering  

**Problems:**  
- [Find Median from Data Stream](https://leetcode.com/problems/find-median-from-data-stream/)  
- [Kth Largest in Stream](https://leetcode.com/problems/kth-largest-element-in-a-stream/)  
- [Sliding Window Median](https://leetcode.com/problems/sliding-window-median/)  

**Key Skills:** heap balancing, online ordering  

---

## 🔟 🧩 Hybrid / Trick Sorting  
Combines multiple patterns — favorite for deep interviews  

**Examples:**  
- [Wiggle Sort II](https://leetcode.com/problems/wiggle-sort-ii/) → Selection + DNF + Reindexing  
- [Reverse Pairs](https://leetcode.com/problems/reverse-pairs/) → Merge + Counting  
- [Largest Number](https://leetcode.com/problems/largest-number/) → Custom Comparator + String Sort  
- [Count of Smaller Numbers After Self](https://leetcode.com/problems/count-of-smaller-numbers-after-self/) → Merge + BST Hybrid
