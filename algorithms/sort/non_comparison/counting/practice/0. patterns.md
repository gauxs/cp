# Counting Sort Patterns Cheat Sheet

## Pattern: Frequency Counting

**Use when:** Keys in bounded range or frequency-based ordering.

**Pattern:** Count occurrences, then emit keys by frequency or reconstruct sorted order from counts.

**Key insight:** Linear when range $k$ is manageable.

### Key skills

- counting array sizing
- stable reconstruction from counts
