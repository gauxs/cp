# Backtracking Patterns Cheat Sheet

## Pattern: Enumerate Choices

**Use when:** Generate all permutations, combinations, or subsets from a finite set of choices.

**Pattern:** Choose, recurse with the reduced choice space, then undo.

**Key insight:** A start index or used set prevents invalid reuse and duplicate generation.

### Key skills

- Distinguish permutations from combinations
- Skip duplicate values at the same recursion depth
- Record a copy of the current path

## Pattern: Constraint-Guided Search

**Use when:** Partial choices must satisfy structural constraints before the solution is complete.

**Pattern:** Reject invalid partial states immediately and recurse only through feasible choices.

**Key insight:** Incremental validity checks avoid constructing complete invalid candidates.

### Key skills

- Skip equal candidates at one decision level
- Mark and restore board or path state
- Precompute fast conflict checks
